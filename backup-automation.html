برنامه بکاپ‌گیری سرویس‌های دیتابیس

مناسب برای سرویس‌های Docker داخل VM

اصل مهم: باید از خود سرویس‌ها بکاپ منطقی یا سرویس‌محور بگیریم و خروجی را به یک مقصد خارجی منتقل کنیم.

دامنه بکاپ

ضروری

PostgreSQL

بکاپ کامل از دیتابیس‌ها، کاربران، roleها و در حالت حرفه‌ای آرشیو WAL.

روش: Logical Backup + در آینده PITR
ضروری

MongoDB

بکاپ از دیتابیس‌ها، collectionها، indexها و کاربران MongoDB.

روش: mongodump همراه با oplog
در صورت وجود فایل مهم

MinIO

بکاپ objectها، bucketها، نسخه‌ها، policyها و تنظیمات دسترسی.

روش: Replication یا Mirror به مقصد خارجی
وابسته به نوع استفاده

Redis

اگر فقط Cache است، بکاپ ضروری نیست. اگر session، queue یا داده اصلی دارد، باید بکاپ گرفته شود.

روش: RDB و در صورت نیاز AOF

مخزن خارجی S3 یا MinIO مستقل

بکاپ نباید فقط داخل همان VM یا همان MinIO نگهداری شود؛ چون خرابی VM یا دیسک می‌تواند هم سرویس اصلی و هم بکاپ را از بین ببرد.

سرویس عملیات زمان‌بندی Retention پیشنهادی

تنظیمات Docker Compose، policy و config روزانه و بعد از هر تغییر ۳۰ روز یا بیشتر

مراحل پیاده‌سازی

۱

ایجاد Backup Runner

یک کانتینر یا سرویس مجزا برای اجرای jobهای بکاپ و زمان‌بندی آن‌ها ایجاد شود.

۲

راه‌اندازی مخزن خارجی

یک S3 یا MinIO مستقل خارج از VM ایجاد شود. دسترسی آن فقط برای Backup Runner باشد.

۳

اجرای بکاپ سرویس‌ها

برای PostgreSQL و MongoDB خروجی dump گرفته شود؛ برای Redis فایل persistence و برای MinIO replication یا mirror اجرا شود.

۴

رمزنگاری و انتقال

خروجی‌ها فشرده، رمزنگاری و سپس به مخزن خارجی منتقل شوند. فایل موقت محلی بعد از انتقال موفق حذف شود.

۵

ثبت وضعیت و هشدار

موفق یا ناموفق بودن job، حجم فایل، checksum، مدت اجرا و زمان آخرین بکاپ ثبت شود.

۶

تست Restore

حداقل ماهی یک‌بار بکاپ‌ها روی محیط موقت restore و صحت داده‌ها بررسی شود.

نسخه پیشنهادی برای شروع

  • PostgreSQL: بکاپ منطقی روزانه
  • MongoDB: mongodump روزانه همراه با oplog
  • Redis: فقط اگر داده مهم دارد؛ RDB دوره‌ای
  • MinIO: Versioning و انتقال به MinIO یا S3 خارجی
  • Backup Runner: اجرای زمان‌بندی‌شده و ارسال خروجی به مقصد خارجی
  • Restore Test: حداقل ماهی یک‌بار
بکاپی که Restore آن تست نشده باشد، بکاپ قابل اعتماد محسوب نمی‌شود.
